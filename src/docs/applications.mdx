# Applications Catalog

This page contains all the applications that can be deployed on the Yamify platform. Each application comes pre-configured and can be deployed with just a few clicks.

## Available Applications

### n8n
<img src="/images/n8n.svg" alt="n8n logo" width="80" />

**Description:** n8n is an extendable workflow automation tool. With a fair-code distribution model, n8n can be used to connect anything to everything.

**Features:**
- Visual workflow builder
- 200+ pre-built integrations
- Webhooks for realtime events
- Self-hosting capabilities

**Use Cases:**
- Automate repetitive tasks
- Connect different services and APIs
- Trigger actions based on events
- Process and transform data

<img src="/images/code-server.svg" alt="Code Server logo" width="80" />

## Deployment Limitations

> **Important:** You cannot deploy multiple instances of the same application type (e.g., two n8n instances) in the same Yam. To deploy another instance of the same application, you need to create a new Yam.

## Requesting New Applications

If you don't see an application you need, please [contact our support](https://yamify.co/contact) to request it be added to the catalog.

## Application Updates

Applications deployed on Yamify are regularly updated to ensure security and performance. Updates are applied automatically without service disruptions in most cases.

For applications with major version updates that might affect compatibility, you'll receive a notification in advance with detailed information about the changes.
