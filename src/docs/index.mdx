# Welcome to Yamify Documentation

Yamify is an intuitive platform for deploying and managing your cloud applications with ease.

## About this Documentation

This guide will walk you through the complete process of using Yamify, from account creation to managing your deployed applications.

## Key Features

- **Workspace Creation and Management** - Organize your projects and applications
- **Quick Deployment** - Deploy applications in just a few clicks
- **Preconfigured Applications** - Choose from a selection of ready-to-use applications
